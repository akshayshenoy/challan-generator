# Challan Generator (Demo)

A learning project: React (Vite) form + Express server that generates a sample challan PDF with PDFKit.

## Run

```bash
npm install          # installs the helper that runs both apps
npm run install-all  # installs server + client dependencies
npm run dev          # starts server (port 5000) and client (port 5173)
```

Open http://localhost:5173

Works the same in GitHub Codespaces: Code -> Codespaces -> Create codespace, then run the commands above.
